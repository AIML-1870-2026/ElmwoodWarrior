# Turing Patterns Explorer - Technical Specification

## Project Overview
A web-based reaction-diffusion simulation explorer for educational and experimental purposes. The application allows users to visualize and interact with Turing patterns generated by the Gray-Scott model.

## Core Functionality

### Simulation Engine
- Implement Gray-Scott reaction-diffusion model
- Use numerical integration (Euler or Runge-Kutta method)
- Grid size: 256x256 (adjustable based on performance)
- Time step: Small enough for stability (dt = 1.0)
- Diffusion rates: dA = 1.0, dB = 0.5
- Parameters: F (feed rate) and K (kill rate) - user adjustable

### Initial State
- Start with chemical A everywhere
- Small random perturbation of chemical B in center region
- Allow reset to initial conditions

## User Interface Layout

### Canvas Area (Primary)
- Large, square canvas centered on page (minimum 600x600px, responsive)
- Real-time visualization of chemical concentrations
- Interactive: click/drag to add chemical B "seeds"

### Control Panel (Side Panel - Right or Bottom)

#### Preset Patterns Section
- Buttons for common pattern types:
  - "Spots" (F=0.035, K=0.065)
  - "Stripes" (F=0.035, K=0.060)
  - "Spirals" (F=0.014, K=0.054)
  - "Maze" (F=0.029, K=0.057)
  - "Waves" (F=0.014, K=0.045)
  - "Unstable" (F=0.026, K=0.051)
- Each button sets F/K values and resets simulation

#### Parameter Controls Section
- **Feed Rate (F)** slider: range 0.000 to 0.100, step 0.001, display current value
- **Kill Rate (K)** slider: range 0.000 to 0.100, step 0.001, display current value
- Label showing current pattern type (if matches preset)

#### Simulation Controls Section
- **Play/Pause** button - toggle simulation running
- **Reset** button - reinitialize to starting conditions
- **Clear** button - fill with chemical A only
- **Speed** slider - control simulation steps per frame (1-10)

#### Interactive Tools Section
- **Brush Size** slider - control size of interaction (5-50 pixels)
- **Tool Mode** selector:
  - "Add Chemical B" (default)
  - "Add Chemical A"
  - "Random Noise"

#### Visual Settings Section
- **Color Scheme** dropdown:
  - "Grayscale" (white to black)
  - "Heat Map" (blue → cyan → yellow → red)
  - "Viridis" (purple → green → yellow)
  - "Ocean" (dark blue → cyan → white)
  - "Custom" (user-defined gradient)

#### Information Panel Section
- Current F and K values displayed prominently
- FPS counter
- Brief explanation: "Reaction-diffusion simulation based on the Gray-Scott model"

### Parameter Space Map (Optional Advanced Feature)
- Small 200x200px visualization showing F/K parameter space
- X-axis: K (0.045 to 0.070)
- Y-axis: F (0.010 to 0.050)
- Different regions color-coded by pattern type
- Clickable: sets F/K values when user clicks on map
- Current F/K position marked with crosshairs

## Interaction Behaviors

### Canvas Interactions
- **Left Click**: Add selected chemical at cursor position
- **Click + Drag**: Paint selected chemical along drag path
- **Brush size**: Determined by brush size slider
- Visual feedback: show brush circle at cursor position when hovering over canvas

### Preset Buttons
- Click preset → Set F/K values → Reset simulation → Start running

### Parameter Sliders
- Real-time update of F/K values
- Simulation continues with new parameters (no automatic reset)
- Smooth transitions between parameter values

### Control Buttons
- **Play/Pause**: Toggle between running and paused states, update button text
- **Reset**: Return to initial conditions (A everywhere, B in center), keep current F/K
- **Clear**: Fill entire grid with chemical A, set B to zero everywhere
- **Speed**: Multiply simulation iterations per render frame

## Algorithm Details

### Gray-Scott Equations
```
dA/dt = dA * ∇²A - AB² + F(1-A)
dB/dt = dB * ∇²B + AB² - (K+F)B
```

### Laplacian Calculation
Use 9-point stencil for better isotropy:
```
     0.05  0.2  0.05
     0.2  -1.0  0.2
     0.05  0.2  0.05
```

### Update Steps
1. Calculate Laplacians for A and B
2. Compute reaction terms: AB²
3. Update A and B using equations
4. Apply periodic boundary conditions (wrap-around)
5. Clamp values to [0, 1] range

Julia Sets

Each pixel represents a complex number z. We repeatedly apply z = z² + c and color the pixel by how quickly z escapes to infinity. Points that never escape form the filled Julia set (the dark region).

The c Parameter

The constant c defines which Julia set you see. Small changes to c can dramatically reshape the fractal. Use the Real/Imag sliders or click on the Mandelbrot set to choose a c value.

The Mandelbrot Set

The Mandelbrot set is a map of all possible Julia sets. Each point on the Mandelbrot set corresponds to a c value. Points inside the Mandelbrot set produce connected Julia sets; points outside produce dust-like ones.

Colors

Colors represent escape speed. Smooth coloring uses the fractional iteration count so gradients flow naturally. Areas that never escape are drawn in the palette's base color.

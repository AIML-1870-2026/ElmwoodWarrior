# Julia Set Explorer — Design Document

## Project Overview

A fully interactive web-based fractal explorer that allows users to visualize and navigate Julia Sets and the Mandelbrot Set. The application provides an intuitive interface for mathematical exploration, featuring smooth animations, customizable color schemes, and deep zoom capabilities.

---

## Core Concepts

### What is a Julia Set?

A Julia Set is generated by iterating the complex function:

```
f(z) = z² + c
```

For each point `z₀` in the complex plane, we repeatedly apply this function:
- z₁ = z₀² + c
- z₂ = z₁² + c
- z₃ = z₂² + c
- ... and so on

If the sequence **escapes to infinity** (|zₙ| > 2), the point is outside the Julia Set. If it **remains bounded**, the point is inside. The boundary between these regions creates the fractal structure.

### Relationship to the Mandelbrot Set

The Mandelbrot Set is the "map" of all Julia Sets:
- Each point `c` in the Mandelbrot Set corresponds to a **connected** Julia Set
- Points outside the Mandelbrot produce **disconnected** Julia Sets (Cantor dust)
- Clicking on the Mandelbrot selects a `c` value and displays its corresponding Julia Set

### 2. Color Palettes

Four distinct color schemes, each using smooth gradient interpolation based on escape iteration count:

#### Rainbow (Spectrum Cycling)
```
Hue cycles 0° → 360° based on iteration count
Saturation: 100%
Lightness: 50% (escaping) | 0% (bounded)
```

#### Fire
| Iteration % | Color |
|-------------|-------|
| 0% | Black (#000000) |
| 33% | Dark Red (#8B0000) |
| 66% | Orange (#FF4500) |
| 100% | Yellow (#FFD700) |
| Bounded | Black |

#### Ocean
| Iteration % | Color |
|-------------|-------|
| 0% | Deep Navy (#000033) |
| 50% | Cyan (#00CED1) |
| 100% | White (#FFFFFF) |
| Bounded | Deep Navy |

#### Synthwave (Neon)
| Iteration % | Color |
|-------------|-------|
| 0% | Deep Purple (#1a0033) |
| 33% | Hot Pink (#FF1493) |
| 66% | Electric Purple (#9400D3) |
| 100% | Cyan (#00FFFF) |
| Bounded | Black |

#### Implementation Note
Use **smooth coloring** (continuous iteration count) to eliminate color banding:
```
smooth_iteration = iteration + 1 - log(log(|z|)) / log(2)
```

### 5. Animation Modes

Three animation types, each with Play/Pause and Speed controls:

#### Orbit Animation
- `c` value rotates in a circle around a center point
- Parameters:
  - Center: (default -0.5 + 0i)
  - Radius: (default 0.5)
  - Speed: rotations per second
- Creates hypnotic, continuously morphing Julia Sets

#### Path Animation
- `c` traces along the boundary of the Mandelbrot Set
- Uses parametric path through interesting regions
- Showcases the variety of Julia Set shapes

#### Preset Morph
- Smoothly interpolates between two preset `c` values
- Linear interpolation in complex plane:
  ```
  c(t) = c₁ × (1 - t) + c₂ × t
  ```
- User selects start and end presets
- Duration control (default: 3 seconds per transition)

#### Animation Controls
| Control | Function |
|---------|----------|
| ▶️ Play | Start animation |
| ⏸️ Pause | Pause animation |
| ⏹️ Stop | Stop and reset |
| 🐢 ↔ 🐇 | Speed slider |

## Technical Specifications

### Rendering

| Parameter | Value |
|-----------|-------|
| Default canvas size | 800 × 600 (or responsive) |
| Maximum iterations | 256 (adjustable for performance) |
| Escape radius | 2.0 |
| Coloring method | Smooth/continuous iteration count |

### Default Views

**Mandelbrot Set:**
- Center: (-0.5, 0)
- Range: x ∈ [-2.5, 1.0], y ∈ [-1.25, 1.25]

**Julia Set:**
- Center: (0, 0)
- Range: x ∈ [-2.0, 2.0], y ∈ [-1.5, 1.5]

### Performance Considerations
- Use `requestAnimationFrame` for animations
- Consider Web Workers for computation (stretch goal)
- Render at lower resolution while zooming/panning, then refine
- Cache computed fractals when possible
